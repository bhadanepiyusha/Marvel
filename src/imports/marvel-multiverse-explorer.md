🔥 FINAL FIGMA MAKE PROMPT – MARVEL MULTIVERSE EXPLORER

Design a high-fidelity, cinematic, dark-themed responsive website called “Marvel Multiverse Explorer.”

This must feel like an immersive storytelling experience, not a basic movie listing website. Focus on strong visual hierarchy, layered black backgrounds, bold typography, and dramatic spacing.

Use Auto Layout and an 8pt spacing system.

FRAME SETUP

Create:

Desktop frame: 1440px width (12-column grid)

Tablet frame: 768px width

Mobile frame: 390px width (4-column grid)

Max content width: 1200px centered

🎨 DARK BACKGROUND SYSTEM (IMPORTANT)

Do NOT use flat #000000.

Use layered blacks:

Base background: #0A0A0F
Section variation: #0F0F14 / #14141C
Card background: #151520

Add subtle radial red glow in hero section.
Use high contrast white typography.

Accent colors:

Marvel Red: #E10600

Electric Blue: #1F80FF

Optional Purple: #6A00FF

Text:

Primary: #FFFFFF

Secondary: #B3B3B3

No white cards. No light backgrounds.
